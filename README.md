# COMSOL Heatsink Analysis — Repository

Analysis pipelines turning raw COMSOL exports and IR-camera experiment data into
figures and metrics for the heatsink study.

## Repository structure

```
simulated_data.py        # SIM pipeline (COMSOL)  -> heatsink_metrics.csv + H figures
experimental_data.py     # EXP pipeline (IR)      -> exp_outer_metrics.csv + E figures
comparison.py            # SIM vs EXP             -> comparison table + C figures
sim_loaders.py           # shared COMSOL loaders + CONFIG
sim_graphics.py          # shared plotting helpers
sensitivity_analysis.py  # parameter sensitivity analysis
bioheat_comparison.py    # regular vs bioheat COMSOL runs
make_readable_tables.py  # optional: publication-ready grouped tables
Final files/             # simulation exports (Probes.csv, Surface.csv)
data/                    # experiment data (IR frames + VC logs)
```

## The three main pipelines (run in order)

Pipelines 1 and 2 are independent and can run in parallel; pipeline 3 needs both.

```bash
# 1. Simulation (COMSOL) — heatsink_metrics.csv + H1..H20 figures
python simulated_data.py

# 2. Experiment (IR camera) — exp_outer_metrics.csv + E1..E13 figures
python experimental_data.py

# 3. SIM vs EXP comparison — comparison table + C1..C10 figures
python comparison.py

# 4. Optional: readable grouped tables (xlsx/csv/md/latex)
python make_readable_tables.py
```

## Data

- `Final files/` holds the COMSOL exports consumed by `sim_loaders.py`
  (`Probes.csv`, `Surface.csv`). Large binary exports and backup zips are not
  tracked in version control (see `.gitignore`; use Git LFS if needed).
- Experiment data lives alongside the scripts (e.g. `Castell22C_7Oct30mm/`,
  `Castell22C_7Oct40mm/`) and is referenced from `experimental_data.py`.

## Requirements

```
numpy pandas matplotlib scipy openpyxl
```

Install with: `pip install -r requirements.txt`

## Notes

- Output directories (`OUTPUT/`, `OUTPUT_auto/`, `OUTPUT_fixed/`) and caches
  (`__pycache__/`, `*_cache/`) are gitignored — they are regenerated by running
  the pipelines.
- `sim_loaders.py` resolves `Final files/` relative to the repository root, so
  the repo can be moved to another machine without editing paths.
